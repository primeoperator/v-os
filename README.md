# V-OS Launcher

Игровой домашний экран для Android на Kotlin + Jetpack Compose. Приложения превращаются в объекты в уютных 2D-комнатах — «Создание», «Связь», «Быт», «Отдых». Нажатие запускает настоящее приложение.

## Возможности

- Работает как приложение «Домой» (`MAIN` + `HOME` + `DEFAULT`) и запрашивает роль через `RoleManager`.
- Список приложений берётся из `PackageManager` и обновляется при установке, удалении и обновлении пакетов.
- Четыре комнаты со своей палитрой, нарисованной в Canvas (без картинок и ассетов). Светлая и тёмная темы.
- Telegram, браузер, камера и GitHub получают заранее подобранные стартовые места; остальное раскладывается сеткой.
- Режим редактирования: долгое нажатие (на объект или на пустое место) или кнопка «Редактировать».
  - перетаскивание объектов пальцем (если в комнате много приложений, комната прокручивается по вертикали);
  - нажатие на объект открывает выбор комнаты;
  - «Готово», кнопка «Назад» или «Домой» выходят из режима.
- Раскладка сохраняется в DataStore. Настройки: имя, тема, звуки, сброс расположения, кнопка «Сделать V-OS домашним».
- Лёгкий тактильный отклик (`HapticFeedback`) и мягкие звуки, синтезируемые в коде (файлов нет).
- Edge-to-edge, безопасные зоны, зоны нажатия не меньше 48 dp, текст не мельче 12 sp.

## Что НЕ делает приложение

Нет root, Accessibility Service, чтения содержимого других приложений, кейлоггинга, сети и аналитики. В манифесте нет разрешений; для видимости приложений используется только `<queries>` (запускаемые активности и обработчики https). `QUERY_ALL_PACKAGES` не нужен.

## Требования

- Android Studio (актуальная стабильная версия) или JDK 17+ для сборки из командной строки.
- Android SDK Platform 36.
- Телефон с Android 8.0 (API 26) или новее.

## Сборка APK

### Вариант 1. Android Studio

1. `File → Open` и выберите папку проекта.
2. Дождитесь синхронизации Gradle.
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
4. APK: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 2. Командная строка

```bash
./gradlew assembleDebug        # Windows: gradlew.bat assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 3. GitHub Actions (без Android Studio)

1. Загрузите проект в репозиторий GitHub.
2. Откройте вкладку **Actions → Build debug APK → Run workflow** (или просто сделайте push в `main`).
3. Скачайте артефакт `vos-launcher-debug-apk`.

## Установка на телефон

**Через USB (adb):**

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

**Без компьютера:** скопируйте `app-debug.apk` на телефон, откройте файл и разрешите установку из этого источника.

## Сделать V-OS домашним экраном

1. Откройте V-OS → ⚙️ → **«Сделать V-OS домашним»** и подтвердите выбор в системном окне.
2. Либо вручную: *Настройки → Приложения → Приложения по умолчанию → Домашнее приложение → V-OS*.

Вернуть прежний лаунчер можно в том же месте настроек.

## Структура проекта

```
app/src/main/java/app/vos/launcher/
├── MainActivity.kt            HOME-активность, роль «Домой», получатель событий пакетов
├── LauncherViewModel.kt       единое состояние, раскладка, настройки
├── model/Models.kt            AppItem, Room, LayoutState, Placement, SettingsState
├── data/
│   ├── LauncherRepository.kt  PackageManager: список приложений, иконки, запуск
│   ├── DataStoreRepository.kt раскладка и настройки (DataStore Preferences + JSON)
│   ├── RoomClassifier.kt      комната по умолчанию и стартовые позиции
│   └── LayoutPlanner.kt       расстановка новых приложений по свободным местам
└── ui/
    ├── VosApp.kt              корневой экран
    ├── HomeWorld.kt           2D-сцена, объекты, перетаскивание
    ├── EditMode.kt            плашка редактирования, выбор комнаты
    ├── Settings.kt            экран настроек
    ├── Chrome.kt              шапка и нижняя панель
    ├── Backdrop.kt            нарисованные комнаты
    ├── Feedback.kt            haptics и звуки
    └── theme/Theme.kt         светлая/тёмная темы, палитры комнат
```

## Как настроить под себя

- **Какое приложение в какой комнате:** `data/RoomClassifier.kt` (списки пакетов и ключевых слов). Любое приложение можно переселить вручную в режиме редактирования.
- **Стартовые позиции особых приложений:** функция `featuredSpot` там же (`x` — доля ширины 0..1, `y` — dp сверху).
- **Размеры объектов и сетки:** `SceneMetrics` в `model/Models.kt`.
- **Цвета комнат:** `roomTheme` в `ui/theme/Theme.kt`.

Положение хранится как доля ширины и dp сверху, поэтому раскладка не ломается на экранах разной ширины.

## Проверка после установки

1. Все ли установленные приложения появились в комнатах (Telegram — «Связь», GitHub и камера — «Создание», браузер — «Быт»).
2. Нажатие на объект запускает нужное приложение.
3. Долгое нажатие включает режим: объекты покачиваются и перетаскиваются; после «Готово» и перезапуска V-OS позиции сохранились.
4. Нажатие на объект в режиме редактирования открывает выбор комнаты.
5. Установка и удаление приложения обновляют сцену.
6. Тема «Светлая/Тёмная» и «Система» переключаются; «Сбросить расположение» возвращает стартовые места.
7. Кнопка «Домой» при открытом V-OS закрывает настройки и режим редактирования.

## Если сборка не проходит

- **«requires compileSdk 37» или «requires AGP 9.2»:** какая-то зависимость новее ожидаемого. Версии зафиксированы в `gradle/libs.versions.toml`; проще всего оставить `composeBom = "2026.01.01"` либо поднять `compileSdk` в `app/build.gradle.kts` и AGP вместе с Gradle-wrapper (Android Studio сделает это через *Tools → AGP Upgrade Assistant*).
- **«SDK location not found»:** создайте `local.properties` со строкой `sdk.dir=/путь/к/Android/Sdk` (Android Studio делает это сам).
- **Иконки или список приложений неполные:** на некоторых прошивках (MIUI, ColorOS, One UI) в настройках приложения может быть отдельное ограничение на «список установленных приложений» — разрешите его для V-OS.

## Известные ограничения

- Объект нельзя перетащить в другую комнату за один жест: для переселения используется нажатие на объект в режиме редактирования.
- Во время перетаскивания комната не прокручивается автоматически: двигайте объект по частям.
- Виджеты, папки и ярлыки (shortcuts) не поддерживаются: это MVP.
